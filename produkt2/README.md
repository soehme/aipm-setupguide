# Produkt 2: SchichtTausch

Dieser Ordner enthält den Kontext zu einem zweiten Produkt.

Er liegt bewusst getrennt von `leihsdir/` und `produkt3/`: Jedes Produkt hat eigene Nutzer, eigene Ziele und eigenes Vokabular. Vermischt man die Ordner, vermischt der KI-Assistent die Produkte -- und schlägt für SchichtTausch plötzlich Funktionen aus der Verleih-App vor.

Wenn du mit dem Assistenten an einem Produkt arbeitest, verweise gezielt auf dessen Ordner.
